
2. What is pip?

pip is Python’s traditional package manager.
It installs libraries into your environment.

pip install -r requirements.txt



3. What is requirements.txt?

A text file listing dependencies.
This lets someone recreate the same environment.
- reproducibility
- everyone uses same versions



4. What is Poetry?

Poetry is an alternative to pip
Poetry is a newer tool that:

manages dependencies
manages virtual environments
manages project metadata



5. What is pyproject.toml?

Modern Python project configuration file.
it defines project dependencies
Poetry reads it

you control the environment manually

creates and manages environment automatically
isolates everything per project

pip → installs into global / venv manually
Poetry → manages isolated environment + lockfile
